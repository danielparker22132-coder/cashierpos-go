# CashierPOS Go — كاشير بلس (نسخة Go)

نسخة Go من برنامج الكاشير CashierPOS — خادم HTTP واحد (stdlib فقط) يخدم
واجهة ويب عربية RTL كاملة + API JSON، على قاعدة SQLite محلية.
**بدون CGO** (عبر `modernc.org/sqlite`) فيُبنى على ويندوز بأمر `go build` واحد.

## التشغيل

المتطلبات: Go 1.24.

```sh
export PATH=$HOME/go-install/go/bin:$PATH
export GOCACHE=/dev/shm/gocache GOPATH=$HOME/go-pkg GOMODCACHE=$HOME/go-pkg/pkg/mod GOTMPDIR=/dev/shm
export GOTOOLCHAIN=local GOFLAGS=-mod=mod

go run ./cmd/cashierpos
# ثم افتح http://localhost:8080
```

خيارات: `-addr :8080` لتغيير المنفذ، `-db cashierpos.db` لمسار قاعدة البيانات
(أو متغير البيئة `CASHIERPOS_DB`).

للبناء التنفيذي:

```sh
go build -o cashierpos ./cmd/cashierpos
./cashierpos
```

على ويندوز (من نفس الشجرة، بلا أي تعديل):

```bat
go build -o cashierpos.exe ./cmd/cashierpos
cashierpos.exe
```

## أول تشغيل

- يُنشأ مدير افتراضي: **admin / admin123** — ويُجبر على تغيير كلمة السر
  عند أول دخول (لا يمكن فتح أي صفحة قبله).
- يُنشأ العميل النقدي الافتراضي «عميل نقدي» (ID=1).
- منطقة التوصيل الافتراضية: «ناجي حمادي» برسوم **0** (توصيل مجاني).
- لا توجد منتجات ولا عروض مزروعة — الكتالوج يبدأ فارغاً ويُستورد/يُدخل يدوياً.

## الأدوار

`admin` (مدير النظام)، `manager` (مدير)، `cashier` (كاشير)،
`supervisor` (مشرف)، `warehouse` (أمين مخزن، قراءة/مخزون فقط).
**Manager = Admin في كل الصلاحيات** (قرار جوني 2026-11-21).
الصلاحيات تُفحص في طبقة الخدمة، لا في الواجهة فقط (جدول §15 الكامل
في `~/workspace/pyqt-cashierpos/FEATURE_MAP.md`).

## القواعد الصارمة

- **السالب ممنوع في كل مكان**: درج، مخزون، أرصدة عملاء/موردين/مندوبين،
  مصروفات، مرتجعات، خصومات — الرفض برسالة عربية واضحة قبل النزول تحت
  صفر، والصفر مسموح.
- البيع يتطلب شيفتاً مفتوحاً لنفس المستخدم في تاريخ اليوم؛ الشيفت يُفتح
  بزر الموظف فقط، واليوم الجديد يبدأ برصيد افتتاحي يُكتب من صفر.
- رقم الفاتورة عدد صحيح متسلسل عالمي (1، 2، 3…) لا يتكرر أبداً،
  محمي بعلامة high-water دائمة.
- كل الفلوس بالقرش (int64) والكميات بالملي (3 خانات عشرية) — **لا float**
  في أي مسار مالي.
- تجاوز حد ائتمان العميل يحتاج موافقة مدير، ويُسجَّل في التدقيق.

## التصميم

الاتجاه (مشتق من المنتج نفسه، تطبيق unslop 2026-11-25):

- **المنتج:** برنامج كاشير لمحل (هايبر) — بيع وشيفت ودرج ومخزون وديون، يستخدمه الكاشير والمدير طوال اليوم.
- **الشخصية:** هادئ، دقيق، عملي.
- **العالم:** محل بقالة — رفوف وميزان وفاتورة ورقية؛ والبرتقالي (`#e67e22`) يبقى الـ accent الوحيد، على أسطح محايدة zinc وأزرار بيضاء (قرار جوني 2026-11-25 بعد رفض الثيم الكريمي/البني — نفس اتجاه PyQt المعتمد: `primary #ffffff` و `primary_foreground #171717`).
- **اللحظات:** أرقام اليوم في الرئيسية (مبيعات اليوم رقم كبير)، وإجمالي الفاتورة في شاشة البيع — الغنى في المحتوى لا في الزخرفة.
- **البصمة:** الأرقام والمبالغ بخط mono مع `tabular-nums`، ورقم الفاتورة كعنوان هادئ، وشريط حالة الشيفت بنص صغير هادئ.

الـ tokens (في `internal/web/static/style.css`):

- **الألوان:** ramp محايد zinc للفاتح (`#f5f5f5` خلفية، `#ffffff` بطاقة، `#171717` نص، `#52525b` ثانوي، `#71717a` خافت، حدود `#e5e5e5`) والداكن (`#09090b` / `#18181b` / `#fafafa` / `#d4d4d8` / `#a1a1aa`)؛ accent واحد برتقالي، بلا gradients ولا glow ولا shadows ملوّنة.
- **الأزرار بيضاء (قرار جوني):** كل الأزرار بوجه أبيض ونص داكن وحدود ظاهرة (`#d4d4d8`) في الفاتح، ووجه `#e5e5e5` في الداكن على خلفية شبه سوداء؛ الـ accent لا يملأ أي زر أبداً — يعلّم الروابط والرابط النشط وحلقة التركيز والرقم الواحد المهم فقط.
- **تباين الـ accent:** `#b45309` كنص على الأبيض 5.02:1، والـ hover `#8f4406` بـ 7.01:1؛ نص `#171717` على `#ffffff` ‎~17:1 والخافت `#71717a` بـ 4.83:1. في الداكن: نص `#fafafa` على `#09090b` ‎~19:1، ونص الزر `#171717` على `#e5e5e5` ‎~15:1، والـ accent `#fb923c` ‎~7.5:1.
- **الأيقونات:** مجموعة خطية واحدة في `internal/web/templates/icons.html` (بكتل `{{define "icon-..."}}` تُستدعى بـ `{{template}}`) — 18px و stroke 1.5 و `currentColor`، بلا إيموجي في الواجهة إطلاقاً وبلا CDN أو خطوط خارجية. زرار العين للباسورد من نفس المجموعة بمقاس 18px.
- **النوع:** أوزان 400-500-600 فقط؛ الأرقام والمبالغ mono و `tabular-nums` بصيغة واحدة (`.num`).
- **التباعد:** شبكة 4px؛ radii متداخلة (عناصر التحكم 8، البطاقات 12).
- **الأجراس:** نص هادئ مع عدّاد mono (`تنبيهات التدقيق 3`)، لا pill أحمر متوهج؛ المعنى كما هو (تدقيق + إشعارات).
- **الحركة:** انتقالات لون/خلفية/حدود فقط (150ms، منحنى `cubic-bezier(0.22,1,0.36,1)`)، بلا `translateY` على hover وبلا pulsing.
- **النصوص:** قصيرة بلا علامات تعجب وبلا ترحيب (`مرحباً …` حُذفت؛ عنوان الصفحة هو اسم السياق) وبلا نقاط في آخر التسميات والأزرار القصيرة.
- جدار بطاقات الـ hub بترتيبه ومحتواه كما هو (إعادة تصميم الـ hub ملغية بأمر جوني)؛ الأقسام وترتيبها لم تتغير في أي شاشة.
- **فورم المبيعات (أُعيد تنظيمه 2026-11-25 بأمر جوني):** صف بيانات الفاتورة (عميل/نوع/دفع) ثم صف إضافة واحد (باركود + منتج + زرار إضافة)، ثم جدول الأصناف بأعمدة واضحة وأرقام محاذاة، ثم صف الدفع (خصم/مدفوع) والتأكيدات، ثم بطاقة إجمالي واحدة ثابتة (الإجمالي/الخصم/الصافي/المتبقي + سطر العروض)، ثم شريط إجراءات ثابت أسفل الفورم (حفظ/طباعة/إلغاء). الطباعة تطبع الشاشة الحالية (`window.print()`)، والإلغاء يمسح أصناف المسودة فقط (نفس F1) — بلا أي تغيير في منطق البيع أو أسماء الحقول أو الـ IDs التي يعتمد عليها الـ JS.
